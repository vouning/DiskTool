# Дисковый инструментарий эникейщика

## Состав
- `disk-tool-gui.ps1` — **GUI-интерфейс** (WinForms, без зависимостей): скан,
  перенос данных с битых секторов, изоляция битых секторов, лог в окне
- `disk-scan.ps1`   — сканер: SMART, здоровье, температура, место на дисках, разделы
- `disk-repair.ps1` — проверка и работа с «мёртвыми» секторами (3 режима скорости)

## GUI-интерфейс (рекомендуется)
Простой запуск — двойной клик по файлу **`disk-tool-gui.vbs`**:
PowerShell стартует в скрытом окне и сразу завершается — консоль не маячит,
рядом с программой остаётся только само окно интерфейса.
(Скрипт также сам прячет свою консоль при любом способе запуска.)

Вручную:
```powershell
powershell -ExecutionPolicy Bypass -File disk-tool-gui.ps1
```
- **Сканировать** — SMART, тома, разделы; результаты в таблице (переключатель «Показать»)
- **Перенести данные с битых секторов** — быстрая коррекция + перенос данных
  в резервную зону диска (Repair-Volume -SpotFix) — секунды
- **Изолировать битые сектора** — полный ремонт (chkdsk /r /x) и remap:
  конроллер отделяет битые сектора от рабочей зоны; для системного тома —
  после перезагрузки
- Кнопки переноса/изоляции требуют прав администратора — ссылка перезапуска
  внутри окна

## Запуск
Сканер (полнее — от администратора, но работает и без прав):
```powershell
powershell -ExecutionPolicy Bypass -File disk-scan.ps1
```

«Починка» (обязательно от администратора):
```powershell
# быстро (секунды): только скан, ничего не меняет
powershell -ExecutionPolicy Bypass -File disk-repair.ps1 -Drive D -Mode Scan

# быстрое исправление найденного (секунды)
powershell -ExecutionPolicy Bypass -File disk-repair.ps1 -Drive D -Mode SpotFix

# полная проверка + перенос данных с битых секторов (минуты-часы, только HDD)
powershell -ExecutionPolicy Bypass -File disk-repair.ps1 -Drive C -Mode Full
```

## Важно про «мёртвые» сектора
Программа не «воскрешает» битые сектора — это невозможно. Принцип такой:
диск сам переносит данные со сбойных секторов в резервную зону (remapping),
а задача инструмента — заставить его это сделать и исключить мёртвые
сектора из использования файловой системой.

- **HDD** — Scan/SpotFix для профилактики, Full после появления битых секторов.
- **SSD** — «лечить» нечего: контроллер сам управляет износом и ячейками.
  Полная проверка только зря тратит ресурс перезаписи.
- Для глубокого перераспределения с ремонтного стенда используются
  специализированные утилиты: Victoria, MHDD, Hard Disk Sentinel.

## Признаки умирающего диска (что искать в отчёте сканера)
- `Здоровье` = Unhealthy / `Статус` = Failed → диск под замену, копируйте данные.
- Рост `Ошибки_чт` / `Ошибки_зап` → накопитель деградирует.
- `Износ` > 90% (SSD) → ресурс ячеек на исходе.
- `Свободно_%` диска системного тома < 15% → замедление, чистить.
